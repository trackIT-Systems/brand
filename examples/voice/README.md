# Voice examples

Raw material for deriving [VOICE.md](../../VOICE.md). Real texts only.

One file per example, named `<good|bad>-<short-topic>.md`, with this header:

```markdown
---
source: <URL, document or "internal">
language: de | en
verdict: good | bad
---

Why: <one or two lines on what works or fails>

<the text>
```

Rewrites of a bad example go below the original, under `## Rewrite`.
